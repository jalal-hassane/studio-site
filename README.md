# studio-site skeleton

Copy this folder's contents into a new **public** GitHub repo named `studio-site`, cloned at `~/studio/studio-site/`, and enable GitHub Pages (Settings → Pages → deploy from the default branch, root folder). GitHub Pages is free for public repos; studio-hub stays private and is never published.

Structure:
```
studio-site/
├── _config.yml        site title
├── index.md           studio home page with the support email
├── privacy/<project>/index.md   one privacy policy per app, generated by /release
└── terms/<project>/index.md     one terms page per app, generated by /release
```

Only `/release` writes here, from a project, using the guarded write procedure (section 8 of the `studio-conventions` skill).
